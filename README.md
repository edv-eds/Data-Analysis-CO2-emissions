# Data-Analysis-CO2-emissions

### A small data analysis project

- Data analysis of changes in CO2 emissions per capita, between 2000 and 2018
- Get a world overview by creating a color coded scatter-plot, displaying attributes of population size, GDP per capita, and emission changes between 2000 and 2018
- Create top list for the 10 best and 10 worst countries when it comes to changes in CO2 emissions per capita
